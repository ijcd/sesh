# sesh v0.4 — plugin SPI + emacs reference plugin — implementation plan

> **Execution:** task-by-task, TDD (failing test → run-red → implement → run-green → commit). Use `superpowers:subagent-driven-development` or `superpowers:executing-plans`.

**Supersedes:** the editor sections of `docs/superpowers/specs/2026-05-25-sesh-v0.4-plugin-spi-design.md` (which baked emacs layout policy into sesh). This plan adopts mechanism-not-policy: core owns lifecycle + envelope; plugins own everything app-shaped; default policy ships as a detachable recipe.

## Overview

Add a plugin SPI so `sesh up` can bring up non-terminal sidecars (editor, later browser/comms) after the terminal layer. Core provides pure mechanism — a factory/instance interface pair, an ordered registry, and a thin `apps:` envelope it routes opaquely to each plugin. Each plugin decides its own config-vs-convention split. The emacs plugin is the reference consumer and stays thin: it forwards to a user-defined elisp hook `(sesh-open-project name cwd files)`, never modeling emacs layout itself. The plugin is mode-agnostic — GUI vs terminal emacs is the user's emacs-config concern, not sesh's; the plugin only dispatches to `emacsclient`. Done = drivers up → plugins up in order; emacs opens a project via the hook; teardown reverses; zero app policy in core.

## Functions

`internal/plugins/plugin.go`
- `Plugin interface { Name() string; New(env ProjectEnv, cfg RawConfig) (Instance, error) }` — registered factory; owns its config schema, defaults, and convention.
- `Instance interface { Up(ctx) error; Down(ctx) error; Validate() []error; DryRun() ([]string, error) }` — one configured unit per `apps[]` entry per `up`.
- `ProjectEnv struct { Name, Cwd string }` — irreducible identity core promises every plugin. Grows only on demonstrated need.
- `RawConfig interface { Decode(into any) error }` — opaque config block; plugin unmarshals into its own struct, never touching the YAML lib.

`internal/plugins/registry.go`
- `Registry.Register(p Plugin) error` — append; reject duplicate `Name`.
- `Registry.Get(name string) (Plugin, bool)` — lookup.
- `Registry.Names() []string` — registration order; drives deterministic dispatch and error copy.

`internal/plugins/raw.go`
- `nodeRaw` wraps a goccy `ast.Node`; `Decode(into)` unmarshals the block. Absent/empty block decodes to the zero value so the plugin can apply convention.

`internal/spec/apps.go`
- `App struct { Plugin, ID string; Optional bool; Raw RawConfig }` — envelope core reads + opaque remainder.
- `App.Key() string` — `plugin + "#" + id`; absent `id` auto-indexed at parse (`emacs`, `emacs#2`) so duplicate plugins don't collide.

`internal/plugins/emacs/emacs.go`
- `New() plugins.Plugin` — factory ctor; lazy `emacsclient` lookup (mirrors kitty `New()`).
- `(p *plugin) New(env, cfg)` — decode emacs config (`hook` name, optional `files`), bind `env`, return instance.
- `(i *instance) Up(ctx)` — ensure daemon (start if client errs), eval the open-form; idempotent.
- `(i *instance) Down(ctx)` — eval the close-form; missing session = no-op.
- `(i *instance) Validate()` — `emacsclient` on PATH; `hook` is a valid symbol; `files` resolve under cwd.
- `(i *instance) DryRun()` — return the `emacsclient` argv it would run.

`internal/plugins/emacs/elisp.go`
- `BuildOpenForm(hook, name, cwd string, files []string) string` — pure; emits a *call* to the user hook, not layout. Strings quote-escaped, paths absolutized.
- `BuildCloseForm(hook, name string) string` — pure.

`internal/engine`
- `Engine.RegisterPlugin(p plugins.Plugin)` / `Engine.Plugins() []string`.
- `runPluginsUp(ctx, e, p)` — decode each `App`, validate, `Up` in registration order; hard-fail unless `App.Optional`.
- `runPluginsDown(ctx, e, p)` — reverse order, best-effort (log, continue).

`internal/config`
- `validateApps(p, reg)` — plugin registered? ids unique? unknown plugin → error naming the registered set.
- `mergeApps(parent, child)` — merge by `Key`; child scalars win; `null`/`drop` removes inherited entry.

## Tests

raw — `TestRawConfig_DecodesBlockIntoStruct` opaque block → typed struct; `TestRawConfig_AbsentBlockDecodesZeroValue` empty block → zero value for convention.

config — `TestValidateApps_UnregisteredPluginErrors` unknown plugin named clearly; `TestValidateApps_DuplicateExplicitIdErrors` collision rejected; `TestMergeApps_ChildScalarWinsByKey` merge-by-key child wins; `TestMergeApps_NullDropsInheritedApp` null sentinel removes.

emacs — `TestEmacs_BuildOpenFormCallsUserHook` golden form is a hook call, no layout; `TestEmacs_UpStartsDaemonWhenClientErrors` daemon spawned on first failure; `TestEmacs_DownIdempotentNoSession` down never-up'd = no error; `TestEmacs_ValidateMissingEmacsclient` clear PATH error; `TestEmacs_DryRunReturnsArgv` preview matches dispatch.

integration (gated `integration_emacs`) — `TestEmacs_RealDaemonOpenClose` spawn daemon, call no-op hook, close.
