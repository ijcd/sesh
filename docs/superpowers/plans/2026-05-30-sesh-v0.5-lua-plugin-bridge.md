# sesh v0.5 — Lua plugin bridge — implementation plan

> **Execution:** task-by-task on `ijcd/spike-lua-bridge` (the spike code is the starting point). TDD where the change is functional; refactor steps may skip TDD when mechanical. Use `superpowers:subagent-driven-development`.

**Supersedes** any earlier v0.5 sketch around "launch primitive + YAML+shell recipes" or "per-app Go plugins." Direction locked: Lua plugins, Go SPI primitives, gopher-lua as substrate. See `docs/superpowers/specs/SPIKE-NOTES.md` for the validation report.

## Overview

Pivot the user-facing plugin layer from Go to Lua. The v0.4 SPI Go contracts (`Plugin`, `Instance`, `RawConfig`, registry, engine wiring) stay unchanged in shape — a Lua bridge satisfies them via an adapter. New plugins are Lua-only (~25–110 lines each); the Go emacs plugin (~250 lines combined) is replaced by a 110-line Lua port. Two interface evolutions land: `DryRun` returns `[][]string` (was `[]string`) so plugins with probe + spawn + dispatch flows can preview the whole sequence; each `LuaPlugin` gets its own LState (was shared in the spike) for isolation. Done = `sesh up` runs Lua plugins by default (no opt-in env var); the v0.4 Go emacs is deleted; Firefox plugin works end-to-end with browser-side session restore handling tab state.

## Functions

### Interface evolution

- `plugins.Instance.DryRun() ([][]string, error)` — was `([]string, error)`. One argv per shell call the plugin would invoke. Plugins with single-argv lifecycles return `[][]string{argv}`. `error` channel kept; decode or build can still fail.

### Bridge polish

- `LuaPlugin` — gain `state *lua.LState` field set at registration time. `discovery.LoadAll` constructs one LState per registered plugin name. ~100µs extra init per plugin; benefit: plugin A can't poison plugin B's globals. Removes the spike's shared-state risk.
- `LuaInstance.DryRun()` — Lua side returns `{ {"bin","arg"}, ... }`; bridge unmarshals into `[][]string`. Empty Lua table returns `[][]string{}` (not nil) so engine.Debug iterates cleanly.
- `sesh.wait_for(predicate, timeout_ms)` — wrap predicate call in `pcall`. On Lua runtime error: log + propagate to Go caller. Spike silently treats predicate errors as "not yet", which hides bugs.

### Firefox plugin

- `firefox.lua` — registers `"firefox"`.
  - `up(env, cfg)` — resolve binary (cfg.binary → PATH → `/Applications/Firefox.app/Contents/MacOS/firefox`); run `bin -CreateProfile <profile>` (idempotent); `sesh.exec_detach(bin, {"-P", profile, "--new-instance", cfg.url?})`.
  - `down(env, cfg)` — no-op unless `cfg.kill_on_down`; then `sesh.applescript` (NB: new API — see below) closing windows whose title contains the profile name.
  - `validate(env, cfg)` — binary resolves; otherwise table with one error string.
  - `dry_run(env, cfg)` — `[][]string` with create + launch argvs.
- `cfg.profile` defaults to `env.name`. `cfg.binary` defaults to PATH then app-bundle fallback.

### Engine adaptation

- `engine.Debug` — for each plugin instance, iterate the `[][]string` from `DryRun()` and print one line per argv under the `# apps[i] <plugin>` header. Preserves the existing single-argv case (length-1 slice → one line, unchanged user-visible output).

### New API helper

- `sesh.applescript(script string) → { stdout, code, error }` — wrapper around `osascript -e`. Not present in the spike; needed by Firefox `kill_on_down`. ~15 lines; mirror `sesh.exec` return shape.

### Removal

- All exports from `internal/plugins/emacs/` (Plugin, Instance, New, BuildOpenForm, BuildCloseForm). Imports removed from `cmd/sesh/root.go`. Tests in `internal/plugins/emacs/*_test.go` deleted with the package.

## Tests

### Bridge (extend `internal/plugins/lua/lua_test.go`)

- `TestBridge_OneLStatePerPlugin` — two plugins register; one mutates a global; the other's global lookup returns unchanged value.
- `TestBridge_DryRunReturnsMultipleArgvLines` — plugin returns 3 argv lines; bridge unmarshals to length-3 `[][]string`.
- `TestWaitFor_PredicateErrorPropagates` — Lua `error()` raised in predicate; bridge returns non-nil error (not silent timeout).
- `TestBridge_RawConfigToLuaTable_Roundtrip` — string, int, bool, list, nested map all readable in Lua.
- `TestBridge_ErrorMarshaling_StringReturn` — Lua up returns `"boom"`; Go gets error containing `"boom"`.

- Firefox `-CreateProfile` latency (~200ms per `Up`): acceptable in hot path, or pre-stage in `sesh new`? Lean acceptable; revisit only if user friction surfaces.
- Delete `internal/plugins/emacs/` in same commit as Lua emacs port lands, or two commits in same PR for blame clarity? Lean two commits.
- Emit `sesh init plugin <name>` scaffolding for user-side Lua plugins? Lean defer to v0.5.1; not on critical path.
- Default `binary` in `firefox.lua` — PATH first then `/Applications/Firefox.app/...`, or app-bundle first then PATH? Lean PATH first (matches kitty's `kittenPath()`).
- Should `sesh.applescript` be in the bridge from v0.5 or deferred? Firefox `kill_on_down` needs it; otherwise no current plugin does. Lean include; ~15 lines.
